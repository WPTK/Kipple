Adding a feed accepts an address as people type or paste it, everywhere a feed address goes in (the add dialog, the Reader API, OPML import, editing a feed's address): `example.com`, `example.com/feed`, `//example.com/feed`, `feed://` and `feed:https://` links (and `pcast:`, `itpc:`, `podcast:`, `rss:`), surrounding spaces, a `#fragment` and an uppercase scheme or host. An address without a scheme gets `https://` when it starts with a host (a name under a real top-level domain, `localhost` or an IP address); a relative path or a file name is still refused. (#266)
