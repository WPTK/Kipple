Failures now say what could not be done and why, in three phrases by cause: "You're offline" (only when the browser has no network), "Kipple can't be reached" (no answer, or an error from a proxy or tunnel in front of a Kipple that is not running) and "Kipple's server had a problem" (an error from Kipple itself). Every failure toast names the action and the cause, a warning looks different from an error, "Try again" is the one retry word, and an error toast clears when the same change later succeeds. (#704)
