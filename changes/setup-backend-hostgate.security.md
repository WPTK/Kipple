During setup and in open mode Kipple answers only requests addressed to an IP address, localhost, a single-word name, a `.local`, `.lan`, `.home.arpa`, `.internal` or `.ts.net` name, or a name listed in `KIPPLE_ALLOWED_HOSTS` or in Settings (421 otherwise), which blocks DNS rebinding. Open mode also refuses requests that arrive through a proxy or tunnel. With a password nothing is refused; an unlisted name is only logged.
