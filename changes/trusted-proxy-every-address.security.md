A trusted proxy range wider than an IPv4 /8 or an IPv6 /32 that covers public addresses (such as `0.0.0.0/0` or `::/0`) is refused: in Settings, and in `KIPPLE_TRUSTED_PROXY_IPS` when it would be stored as the setting (the start stops and says to list only the address your proxy connects from). Every address in a trusted range can choose its own client address. (#265)
