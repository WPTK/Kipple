Over https the session marker cookie is now named `__Host-kipple_signed_in`, so a cookie of the same name set for the whole parent domain by another site on a sibling subdomain can no longer make every launch end in a 401. A browser signed in before this asks the server once at its next launch and gets the new marker. A sign-out clears the marker under both names, so one set before the server saw a different scheme goes too. (#553)
