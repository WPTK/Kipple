An OPML import now lists the feeds on a private address or a local-network name (such as `.lan`) in one place with a single button that allows them all, instead of leaving you to open each feed. A feed on a public name whose file asked to reach your network is not in that list; it keeps its own line. Turning on a feed's own-network access, from that button or from the feed editor, now fetches the feed at once instead of after its retry wait. (#485)
