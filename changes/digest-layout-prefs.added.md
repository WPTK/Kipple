A new Digest layout appears in the layout menu: a page of sections, one for each folder (or feed), each with its first few unread articles and an "N more" button that opens it in place. Sections load as you reach them, so a slow or failing one never holds up the rest. The layout menu sets, for this device, the order of sections (sidebar order or Quiet Feeds First), folders or feeds as sections, pictures or text only, and rows per section. (#39)
