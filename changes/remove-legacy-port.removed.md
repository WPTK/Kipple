The pre-0.5 default port 7080 is no longer kept for old installs: an unset `KIPPLE_ADDR` now always means `:1919` (with the existing `:1138` fallback if it is taken), whatever the database says, and the "port 7080 is the pre-0.5 default" warning is gone. `kipple healthcheck` with `KIPPLE_ADDR` unset probes 1919 then 1138, no longer 7080, and a restore no longer carries a listen port. If your install still publishes 7080 without setting it, set `KIPPLE_ADDR=:7080` in `.env` (keeping the `7080:7080` mapping) or move to 1919 before upgrading, or Kipple will listen on 1919 behind a mapping for 7080 and look down.
