Harden the sign-in cookie and HSTS behind a reverse proxy: a request for the exact origin of an https public URL (its host with no port, or the public URL's own port) now counts as HTTPS even when the proxy is not under Trusted proxies, so the sign-in cookie is marked Secure (Strict-Transport-Security is still sent only for TLS or a trusted proxy's HTTPS). Plain http on a LAN address, or on Kipple's own port, keeps working as before. (#450)
