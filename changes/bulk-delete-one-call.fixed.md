Deleting many feeds at once is no longer a loop in the browser. The web app sends the whole selection in one request and the server marks every feed for deletion in one step before it removes any, then finishes the job even if you close the page, so a closed tab can no longer leave a half-deleted library. The dialog says it keeps going on the server. "Delete the folder and its feeds" does the same. A new `POST /api/feeds/delete` takes the ids. (#486)
