A feed address whose server name is longer than a real one can be (more than 253 characters, or more than 63 between two dots) is refused when it is added, edited or imported, with a message that says so, instead of being saved as a feed that can never be fetched. An OPML file of very long addresses no longer grows the database or memory: none of them is stored, each is listed in the import report with its reason. (#470)
