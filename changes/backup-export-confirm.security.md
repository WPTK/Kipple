Exporting a backup asks for your password: Settings, Account & Devices, Export backup now asks for your web password before it builds the file, the same way generating an API password does (an account without a web password confirms with its Cloudflare Access sign-in; open mode asks for nothing). `POST /api/backup` takes `{"current": "<web password>"}`. The `RESTORE.txt` note in the zip and the export dialog now say that the file contains credentials, including what a Reader app needs to sign in, and should be stored privately.
