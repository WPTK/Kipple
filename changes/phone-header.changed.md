On a phone held sideways, the list header keeps the title, the Show pills (a Show menu on a narrow screen) and the feed switch on one row, and the tab bar is one row of icon and name, so a list keeps its height. A phone's list header has no Refresh button: pull the list down, or choose Refresh all feeds in the actions menu, whose icon spins while a refresh runs. Feed health, the Settings groups and Your year all go back with the same chevron before the title, which returns to the screen you came from. The Stats range that draws one bar per month is called Monthly. (#420, #422, #424)
