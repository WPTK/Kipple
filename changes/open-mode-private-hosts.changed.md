Choosing no password (open mode), in the setup wizard or later in Settings, now remembers the name you used at that moment: a single-word name such as `nas` or a `.local`, `.lan`, `.home.arpa` or `.internal` name is added to Settings > Allowed host names (`security.allowed_hosts`) with the change, so Kipple keeps answering it without a password. Open mode still refuses other names of that kind, which any device on your network could point at your computer, and its "refused this address" messages now say how to add another name: under Settings > Allowed host names, or in `KIPPLE_ALLOWED_HOSTS`.
