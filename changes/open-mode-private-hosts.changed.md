Without a password (open mode) Kipple now answers the same names as during setup: any name that cannot be looked up in public DNS, so a single-word name such as `nas` and `.local`, `.lan`, `.home.arpa` and `.internal` names work without being listed in `KIPPLE_ALLOWED_HOSTS`. Public names are still refused, and the refusal now says to set a password, or to list the name if it points only at your own network. If you bound Kipple to `127.0.0.1` to keep other devices on your network out of open mode, set a password instead. (#254)
