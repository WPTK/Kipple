Over https the session cookie is now named `__Host-kipple_session`, so a cookie of the same name set for the whole parent domain by another site on a sibling subdomain can no longer stand in for your session or leave every launch answering 401. This signs everyone out once over https: a browser holding the old `kipple_session` cookie is shown the sign-in form at its next launch, and signing in again clears the old cookie. Signing in or out ends every session the browser holds a cookie for, under either name. Over plain http (a LAN address) the name is unchanged and nobody is signed out. (#571)
