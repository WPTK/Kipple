Removed four settings keys that nothing read or showed: `ui.font_size` (text size is a per-device choice), `ui.font_ui`, `ui.layouts` (list layouts are per-device profile keys) and `stats.api_single_read_is_open` (reads from sync apps never count as statistics). They no longer appear in `GET /api/settings`, `/api/bootstrap` or device profiles, and `PATCH` refuses them as unknown. Rows an existing database holds for them are left in place and ignored. The unused `css` field of the Spacing option list is gone too, and the favorites fallback that kept pinned folders on one device is removed.
