Importing an OPML file reports what happened more clearly. The dialog shows the fetch of the new feeds as it goes, then how many could not be fetched. A feed on your own network is listed once, with the switch in its settings that lets Kipple fetch it. Skipped feeds say why in words that fit an import, and a feed listed twice in the file is counted. An empty file, a file that is not OPML, a file with only empty folders, and a file that uses an entity XML and HTML do not define are each refused with their own message, so a name like "&x;" never becomes a folder. Feed addresses longer than 4,096 characters are refused everywhere. Moving selected feeds starts with no folder chosen. (#467, #470, #485, #487, #464)
