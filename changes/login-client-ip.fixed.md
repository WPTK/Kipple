Web sign-in no longer locks the owner out behind a reverse proxy or Docker's shared gateway: wrong passwords are now slowed per client (five free in ten minutes, then one attempt per two seconds) instead of refused after ten, so the right password always signs in, and the client address comes from one resolver that believes `X-Forwarded-For` (the rightmost hop that is not a listed proxy) or `CF-Connecting-IP` only from a peer in `KIPPLE_TRUSTED_PROXY_IPS`.
